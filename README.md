# 🚖 OLA Ride Analytics Dashboard | Power BI

## 📌 Project Overview

This project is an interactive **Power BI dashboard** built to analyze OLA ride booking data. It provides valuable insights into ride performance, revenue, customer behavior, booking trends, and cancellation patterns through dynamic visualizations.

The dashboard helps stakeholders make data-driven decisions by monitoring key business metrics and identifying operational trends.

---

## 📊 Dashboard Features

- 📈 Total Bookings Analysis
- 💰 Total Revenue Analysis
- 🚗 Ride Status Overview
- ❌ Cancellation Analysis
- ⭐ Customer Ratings
- 👨‍✈️ Driver Performance
- 💳 Payment Method Distribution
- 📍 Ride Distance Analysis
- 📅 Daily & Monthly Booking Trends
- 🎯 Interactive Filters and Slicers
